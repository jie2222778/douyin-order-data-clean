# 抖音电商订单全流程数据清洗项目
## 项目概述
本项目使用Python Pandas完成抖音电商原始订单的数据预处理，针对业务导出订单普遍存在字段空缺、号码格式错乱、时间格式不规范、异常金额、冗余订单状态等脏数据问题，封装清洗函数多维度校验筛选，最终输出仅可直接物流发货的合规订单。
> 郑重声明：项目所有姓名、手机号、收货地址均为模拟虚构测试数据，不存在任何用户隐私信息。

## 项目文件分工
1. generate_order.py：构造内置各类脏数据的原始订单Excel，生成测试数据源
2. clean.py：核心清洗脚本，封装清洗函数，分步校验过滤脏数据，输出合规订单
3. requirements.txt：项目依赖库清单，一键部署运行环境
4. .gitignore：配置git忽略文件，仅上传源码，屏蔽运行生成Excel表格
