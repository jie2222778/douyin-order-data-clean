# 抖音电商订单数据清洗项目
## 一、项目说明
本项目依托Python Pandas对抖音电商导出的原始订单Excel做业务数据清洗，过滤各类脏数据，筛选出满足信息完整、格式合规、状态为待发货的订单，筛选后的表格可直接对接物流进行发货。
**重要声明：项目内所有姓名、手机号、收货地址均为程序构造的虚构模拟数据，不存在任何用户隐私信息。**

## 二、项目文件作用
1. generate_order.py：批量生成带有各类脏数据的原始订单Excel，内置空字段、错误手机号、空白地址、异常金额、不同订单状态等测试数据
2. clean.py：核心数据清洗脚本，加载原始订单，按照业务规则剔除无效订单，导出筛选完毕的待发货合规订单
